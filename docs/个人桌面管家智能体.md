# 个人桌面管家智能体（DeskAgent）

DeskAgent 除了作为 AI 编程 Agent 运行时，还可以变身成为**个人桌面管家智能体**：用自然语言一句话指挥电脑，自主规划并完成监控、清理、卸载、进程管理等桌面管理任务。

## 人物定位

- **称呼**：DeskAgent，个人桌面管家智能体
- **形态**：常驻用户电脑（`desk-core` 守护进程），随时待命
- **交互方式**：自然语言一句话指令（CLI / TUI），不需要记忆命令或脚本
- **能力范围**：监控（CPU / 内存 / 磁盘 / 进程）、清理（临时文件 / 缓存 / 日志 / 回收站）、卸载软件、进程管理，以及日常编程任务

## 行为准则

管家场景下，安全是核心：

1. **权限审批**：破坏性操作（清理、卸载、结束进程等）执行前必须经过用户审批
2. **dry-run 预览**：先给出「将要做什么」的清单，用户确认后再执行
3. **白名单保护**：系统关键路径（白名单）永不删除
4. **操作留痕**：审计日志记录每次操作，可回溯

## 典型场景

- 「看看电脑为什么卡」→ 采集 CPU / 内存 / 磁盘 / 进程指标，定位高占用进程，给出优化建议
- 「帮我清理一下电脑」→ 扫描临时文件、缓存、日志、回收站，先出清单，审批后执行清理
- 「把某软件卸载掉」→ 扫描已安装软件、定位卸载器，审批后执行卸载与残留清理

## 实现状态

系统管理工具集（`system_monitor` / `scan_junk` / `clean_junk` / `uninstall_software` / `process_manage`）为**规划中**，落地后将随能力扩展更新本文。
